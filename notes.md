🏁 УРОК 1. Как работает интернет
Прежде чем писать код — надо понять, где он будет жить.

🌐 Что такое интернет?
Интернет — это огромная сеть связанных компьютеров. Когда ты заходишь на сайт, происходит магия:

Ты вводишь google.com в браузере.

Твой компьютер спрашивает у DNS-сервера: «Какой IP у google.com?»

DNS отвечает: например, 142.250.185.78.

Браузер отправляет запрос на этот IP по протоколу HTTP/HTTPS.

Сервер Google обрабатывает запрос и отправляет обратно HTML-страницу.

Браузер рисует страницу.

🔑 Ключевые понятия
Термин	Что это
Клиент	Твой браузер (Chrome, Firefox). Он запрашивает.
Сервер	Компьютер, который отвечает на запросы.
IP-адрес	Уникальный «номер» компьютера в сети.
DNS	«Телефонная книга» интернета: домен → IP.
HTTP	Протокол общения клиента и сервера.
HTTPS	То же, но зашифрованное (безопасное).
Порт	«Дверь» на сервере (80 для HTTP, 443 для HTTPS).
📨 HTTP-запрос: что внутри?
Методы (глаголы):

GET — получить данные (открыть страницу).

POST — отправить данные (залогиниться, оставить коммент).

PUT / PATCH — обновить.

DELETE — удалить.

Статус-коды ответа:

200 OK — всё хорошо.

301/302 — редирект.

404 — не найдено.

500 — ошибка сервера.

🏗️ Что такое Frontend и Backend?
Frontend — то, что видит пользователь: HTML, CSS, JS, React. Работает в браузере.

Backend — то, что на сервере: логика, база данных, авторизация. Работает на сервере.

Full-Stack — умеет и то, и другое. 👑 Это наша цель.

🟠 УРОК 5. Основы HTML
📚 Что такое HTML?
HTML (HyperText Markup Language) — это не язык программирования, а язык разметки. Он говорит браузеру, что находится на странице: это заголовок, это абзац, это картинка, это ссылка.

Представь, что HTML — это скелет человека. Пока нет мышц (CSS) и нервной системы (JavaScript), но именно скелет определяет, где будет голова, руки и ноги.

🧱 Анатомия HTML-элемента
Элемент состоит из тега (команда браузеру) и содержимого (то, что внутри):

html
<h1>Привет, мир!</h1>
<h1> — открывающий тег (начало элемента).

Привет, мир! — содержимое (текст, который увидит пользователь).

</h1> — закрывающий тег (конец элемента, с косой чертой).

Некоторые элементы самозакрывающиеся — у них нет содержимого, например, <img> (картинка) или <br> (перенос строки).

🏗️ Структура HTML-документа
У каждой веб-страницы есть обязательный каркас:

html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Моя первая страница</title>
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это мой первый абзац на HTML.</p>
</body>
</html>
Разберём по частям:

Элемент	Что делает
<!DOCTYPE html>	Говорит браузеру: «Это документ HTML5». Всегда первая строка.
<html>	Корневой элемент, обёртка для всего документа. Атрибут lang="ru" указывает язык.
<head>	«Голова» документа. Здесь метаданные: кодировка, заголовок вкладки, подключение стилей. Пользователь этого не видит.
<body>	«Тело» документа. Всё, что видит пользователь на странице, находится здесь.
📌 Популярные теги
Заголовки (от самого важного к менее важному):

html
<h1>Самый важный заголовок</h1>
<h2>Подзаголовок</h2>
<h3>Ещё меньше</h3>
На странице должен быть только один <h1> — это главный заголовок.

Абзац:

html
<p>Это абзац текста. Внутри него может быть много слов.</p>
Ссылка:

html
<a href="https://github.com">Мой GitHub</a>
Атрибут href указывает, куда ведёт ссылка.

Изображение:

html
<img src="cat.jpg" alt="Кот в шляпе">
src — путь к файлу картинки.

alt — текст, который покажется, если картинка не загрузится (важно для доступности).

🎯 Что такое атрибуты?
Атрибуты — это дополнительные настройки элемента. Они пишутся внутри открывающего тега в формате имя="значение".

html
<a href="https://github.com" target="_blank">Открыть в новой вкладке</a>
Здесь target="_blank" — атрибут, который открывает ссылку в новой вкладке.
🟠 УРОК 6. Введение в CSS
📚 Что такое CSS?
CSS (Cascading Style Sheets) — это язык стилей. Если HTML — это скелет (структура), то CSS — это одежда, макияж и причёска. Он отвечает за внешний вид: цвета, шрифты, отступы, размеры, расположение элементов.

🔗 Как подключить CSS к HTML?
Есть три способа, но мы будем использовать самый правильный — внешний файл. Это когда стили лежат в отдельном файле style.css.

Создай файл style.css рядом с index.html.

В index.html внутри <head> добавь одну строчку:

html
<link rel="stylesheet" href="style.css">
Всё! Теперь браузер знает, что нужно взять стили из этого файла.

🧱 Синтаксис CSS
CSS-правило состоит из селектора и блока объявлений:

css
h1 {
  color: red;
  font-size: 32px;
}
h1 — селектор (к чему применяем стиль).

{ ... } — блок объявлений.

color: red; — свойство и значение (что именно меняем).

; — точка с запятой в конце каждого объявления (обязательно!).

🎯 Виды селекторов
Селектор	Синтаксис	Пример	Что делает
Тег	h1	h1 { color: red; }	Ко всем <h1> на странице
Класс	.имя	.card { padding: 20px; }	Ко всем элементам с class="card"
ID	#имя	#main-title { color: blue; }	К одному уникальному элементу с id="main-title"
Классы — самый частый способ. Ты добавляешь в HTML атрибут class="...", а в CSS пишешь .имя-класса.

🎨 Основные свойства
Цвета:

css
color: #333333;           /* цвет текста */
background-color: #f0f0f0; /* цвет фона */
Цвета можно задавать словами (red, blue), HEX-кодами (#ff0000) или RGB (rgb(255, 0, 0)).

Шрифты:

css
font-family: Arial, sans-serif;
font-size: 16px;
font-weight: bold;
text-align: center;
Отступы (Box Model):

margin — внешний отступ (расстояние от элемента до других).

padding — внутренний отступ (расстояние от границы до содержимого).

css
p {
  margin: 10px;
  padding: 15px;
}
Границы:

css
border: 2px solid black;
border-radius: 8px; /* скругление углов */
🟠 УРОК 7. Flexbox — учимся располагать элементы
📚 В чём проблема?
Сейчас все твои элементы идут друг за другом сверху вниз. Это стандартное поведение блочных элементов. Но что, если мы хотим:

Поставить две карточки рядом (в линию)?

Сделать навигацию в шапке сайта (логотип слева, меню справа)?

Отцентрировать блок идеально по центру экрана?

Для этого придумали Flexbox — один из самых мощных инструментов CSS.

🧠 Как это работает?
Flexbox применяется к родителю, а управляет детьми.

Представь, что у тебя есть контейнер и три коробки внутри него:

html
<div class="container">
  <div class="box">1</div>
  <div class="box">2</div>
  <div class="box">3</div>
</div>
Чтобы включить Flexbox, нужно написать в CSS для родителя:

css
.container {
  display: flex;
}
Всё! Коробки сразу встанут в ряд (слева направо). По умолчанию Flexbox выстраивает элементы в строку.

🎛️ Главные свойства Flexbox
1. display: flex — включает режим Flexbox.

2. flex-direction — задаёт направление:

row (по умолчанию) — слева направо.

column — сверху вниз.

3. justify-content — выравнивание по главной оси (горизонтально, если row):

flex-start — в начале (слева).

center — по центру.

flex-end — в конце (справа).

space-between — первый элемент слева, последний справа, между ними равные промежутки.

space-around — равные отступы вокруг каждого элемента.

4. align-items — выравнивание по поперечной оси (вертикально, если row):

stretch (по умолчанию) — растягивает элементы по высоте.

center — по центру.

flex-start — вверху.

flex-end — внизу.

5. gap — расстояние между элементами.
🟠 УРОК 8. Семантические теги и структура сайта
📚 Что такое семантика?
До этого мы использовали <div> — это просто «коробка» без смысла. Браузер не знает, что внутри: шапка сайта, меню или подвал. Поисковики (Google, Яндекс) и программы для незрячих людей тоже не понимают, что где.

Семантические теги — это теги, которые описывают смысл содержимого. Они делают код понятным для всех.

🏗️ Основные семантические теги
Тег	Что означает
<header>	Шапка сайта или раздела (логотип, название).
<nav>	Навигация (меню, ссылки).
<main>	Основное содержимое страницы (уникальное для каждой страницы).
<section>	Смысловой раздел (например, «О нас», «Услуги»).
<article>	Независимая статья (пост в блоге, карточка товара).
<aside>	Боковая панель (реклама, виджеты, ссылки).
<footer>	Подвал сайта (копирайт, контакты).
🖼️ Типичная структура сайта
Представь стандартный сайт:

text
┌─────────────────────────────┐
│           HEADER            │  ← Логотип + меню (nav)
├─────────────────────────────┤
│           MAIN              │  ← Основной контент
│  ┌───────────┐ ┌─────────┐  │
│  │  SECTION  │ │ ARTICLE │  │
│  └───────────┘ └─────────┘  │
├─────────────────────────────┤
│           FOOTER            │  ← Контакты, копирайт
└─────────────────────────────┘
🟠 УРОК 9. CSS Grid — король раскладок
📚 В чём разница между Flexbox и Grid?
Ты уже знаешь Flexbox. Он отлично подходит для одномерных раскладок: выстроить элементы в ряд или в колонку.

Но что, если нужно создать сложную сетку? Например, галерею из 9 картинок, где одна занимает 2 колонки и 2 строки? Или классический макет сайта: шапка сверху, сайдбар слева, контент по центру, виджеты справа?

Для этого придумали CSS Grid. Это двумерная система: она управляет и строками, и колонками одновременно.

Простая аналогия:
Flexbox — это полка, на которую ты ставишь предметы в линию.
Grid — это шахматная доска, где ты сам решаешь, куда поставить каждую фигуру.

🧱 Основы Grid
css
.container {
  display: grid;                                  /* Включаем Grid */
  grid-template-columns: 1fr 1fr 1fr;             /* 3 колонки равной ширины */
  grid-template-rows: 100px 200px;                /* 2 строки заданной высоты */
  gap: 20px;                                      /* Расстояние между ячейками */
}
Единица измерения fr (fraction) — это «доля свободного места». 1fr 1fr 1fr означает «разделить ширину поровну на три части».

🎛️ Полезные свойства
Адаптивная сетка без медиа-запросов:

css
grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
Это магия. Браузер сам создаст столько колонок по 250px, сколько поместится, а если места мало — перенесёт на новую строку. Идеально для галерей и карточек.

Растягивание элемента на несколько ячеек:

css
.item-1 {
  grid-column: span 2;  /* занять 2 колонки */
  grid-row: span 2;     /* занять 2 строки */
}
